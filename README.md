## 🚀 Project Overview

Spotify.MP3 is a browser-based music player that allows users to enjoy songs with an interactive and visually appealing interface.

The application dynamically loads songs, provides playback controls, and organizes music by **popular singers and nostalgic collections**.

---

## ✨ Features

- Play, Pause & Skip Tracks
-  Dynamic Playlist Rendering
-  Smooth Audio Controls
-  Responsive Design (Mobile + Desktop)
-  Modern Spotify-style UI
-  Animated Transitions
-  Lightweight & Fast Performance
